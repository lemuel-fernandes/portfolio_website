## 📦 Run on localhost

1. Open a terminal in this project folder.
2. Install dependencies (once):

```bash
npm install
```

3. Start the dev server:

```bash
npm start
```

Create React App serves the app at **http://localhost:3000** (the terminal prints the exact URL). Press `Ctrl+C` to stop.

**Requirements:** [Node.js](https://nodejs.org/) LTS (includes `npm`).
